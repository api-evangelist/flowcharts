This new generation features a streamlined API for a smoother developer experience, an intuitive UX for enhanced usability, and a host of new features that make working with diagrams more efficient than ever. Enhanced layout algorithms and layout options help you reach your goals even faster, advanced interaction and viewing features enable more intuitive and dynamic diagrams. The redesigned user interactions closely follow established standards and provide a smoother and more engaging experience for end users. A simplified and more consistent API enables faster and more efficient integration. The included migration tool helps you transition smoothly from previous versions to the new API of this generation. To learn more about these new features see also the About yFiles.NET Version 6.0 page on our yfiles.com website!
